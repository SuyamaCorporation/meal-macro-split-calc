# Macro Split & Meal Plan Calculator
身長・体重・活動レベル・目標を入力しTDEEと三大栄養素ターゲットを計算する食事管理ツール。
## Features
- Mifflin-St Jeor方程式でBMR計算、活動係数をかけてTDEEを算出
- 目標（減量/維持/増量）に応じてカロリー・PFCの最適比率を提案
- 20種類の食品データベースから量を指定してデイリーログに追加
- カロリー・タンパク質・炭水化物・脂質のプログレスバーでリアルタイム管理
- 1食品ずつ削除可能なログ管理
## Usage
体格情報を入力してCalculateボタンを押すとTDEE・マクロターゲットが表示される。食品DBから食品を選んでグラム数を指定しAddするとデイリーログに累積記録される。
